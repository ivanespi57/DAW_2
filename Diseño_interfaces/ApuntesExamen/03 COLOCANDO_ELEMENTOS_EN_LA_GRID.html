COLOCANDO ELEMENTOS EN LA GRID

En todos los ejemplos hasta ahora, hemos confiado en el comportamiento de colocación automática del algoritmo de grid para poner los elementos de grid en celdas secuencialmente. Ese método ciertamente tiene su lugar, pero el verdadero poder de Grid Layout radica en la capacidad de colocar un elemento en la celda específica o área de grid de tu elección. Aquí es donde Grid Layout puede empezar a sentirse un poco complicado, porque hay tantas opciones para hacer lo mismo. Te introduciré a los varios métodos de colocación de elementos y puedes elegir los que sean más cómodos para ti.

Hay dos enfoques generales para colocar elementos en una grid:

• Especificando las líneas de grid en las que el elemento debería comenzar y terminar, ya sea por número de línea o nombre

• Dirigiéndose a un área nombrada de la grid

Posicionando Elementos Usando Líneas de Grid

Introduje el término “línea de grid” brevemente cuando introduje las partes de una grid, pero ahora vamos a ponerlas en uso como puntos de referencia para colocar elementos de grid justo donde queremos que vayan. Puedes referirte a una línea de grid específica por su posición numérica en la grid o por un nombre que le asignes al configurar las pistas de grid.

Usando numeración automática de líneas

Detrás de escena, el algoritmo de grid asigna un número a cada línea en la grid que puedes usar para especificar el punto de inicio y fin de un elemento. Antes de llegar a ejemplos de código, esta es una buena oportunidad para introducir una gran herramienta para visualizar la numeración de líneas de grid y la estructura de grid. Chrome, Safari, Edge y Firefox incluyen cada uno un Inspector de Grid como parte de sus Herramientas de Desarrollador.

FIGURA 7. El Inspector de Grid de Chrome revela los números asignados a cada línea en la grid de ejemplo.

La FIGURA 7 muestra cómo se ve la grid de ejemplo en el Inspector de Grid de Chrome, con el contenido oculto para mayor claridad. Para acceder al inspector en Chrome, selecciona Ver → Desarrollador → Herramientas de Desarrollador. Elige el Inspector de Elementos para que obtengas una vista de la estructura HTML del documento y estilos. Cuando seleccionas el elemento que se ha convertido en un contenedor de grid (div #layout en nuestro ejemplo), la palabra “grid” aparece junto a la etiqueta de apertura. Hacer clic en el botón de grid muestra la superposición del Inspector de Grid en la vista previa de la página.

La línea de grid vertical en el borde izquierdo de la grid tiene asignado el número 1, y las líneas se numeran secuencialmente desde ahí, terminando con la línea en el borde derecho de la grid (ver Nota). La numeración de líneas de grid horizontales (pistas de fila) comienza en la parte superior de la grid y termina con la línea de grid inferior.

NOTA
La dirección de numeración refleja la dirección de escritura del documento. Porque mi documento está en inglés, la numeración va de izquierda a derecha y de arriba a abajo, pero la dirección cambiaría para idiomas con direcciones de escritura alternativas.

Las líneas también se numeran desde el final de las pistas, comenzando con -1 y contando hacia atrás desde ahí (-2, -3, etc.), como se muestra a lo largo de los bordes inferior y derecho en la vista del Inspector de Grid en la FIGURA 18-16. En la estructura de grid de ejemplo, la línea de grid vertical en el borde derecho de la grid podría ser dirigida en una propiedad ya sea por el número 4 o por -1 (nota los números en la superposición). Poder dirigirse al final de una fila o columna sin contar líneas (o incluso saber cuántas filas o columnas hay) es una característica útil. Llegarás a amar ese -1.

CONSEJO
El Inspector de Grid de Chrome también puede mostrar los tamaños de pista y nombres de área en la superposición. Para activar esas opciones, abre el panel de Layout.

Asignando nombres de línea

Si no te gusta llevar la cuenta de números, también puedes asignar nombres de línea que pueden ser más intuitivos. Asignas nombres a las líneas cuando configuras los tamaños de pista con una de las propiedades grid-template-. Escribe cada nombre de línea dentro de corchetes ([]) en la posición en que aparece relativa a sus pistas vecinas (puede que ya hayas probado esto en el EJERCICIO 13-2).

En el siguiente ejemplo, he asignado nombres que corresponden a cómo usaré cada pista en la página final:

Colocando Elementos en la Grid

#layout {
    display: grid;
    grid-template-rows: [header-start] 100px [content-start] 400px
    [footer-start] 100px [footer-end];
    grid-template-columns: [ads] 200px [main] 500px [links] 200px;
}

Basándose en este ejemplo, la línea de grid en la parte superior de la grid ahora puede ser referida como “header-start”, 1, o -4. También podría nombrar la línea que viene después de la primera pista de fila “header-end”, aunque ya le he dado el nombre “content-start”. Para dar a una línea más de un nombre, simplemente incluye todos los nombres en los corchetes, separados por espacios:

grid-template-rows: [header-start] 100px [header-end content-start]
400px [footer-start] 100px [footer-end];

Es común que cada línea de grid termine con múltiples nombres y números, y puedes elegir el que sea más fácil de usar.

Propiedades para posicionamiento

Ahora que sabes cómo referenciar líneas de grid, veamos las propiedades que las usan. Un método para describir la ubicación de un elemento de grid en la grid es especificar las cuatro líneas que bordean el área objetivo usando las propiedades -start y -end. Estas son las primeras propiedades que hemos visto hasta ahora que se aplican a los elementos de grid individuales en lugar del contenedor de grid. Eso tiene sentido, porque estamos manipulando la posición de un elemento a la vez.

grid-row-start
grid-row-end
grid-column-start
grid-column-end

Valores: auto | línea de grid | número de span | nombre de línea span | número ‘nombre de línea’
Por defecto: auto
Se aplica a: Elementos de grid
Hereda: No

Este conjunto de propiedades proporciona una forma directa de describir la posición de un elemento en la grid identificando ya sea el nombre o el número de la línea de grid en cada borde. Como alternativa, puedes proporcionar solo un identificador de línea y decir al elemento que “abarque” un cierto número de celdas (veremos el spanning en un momento). Por defecto, un elemento ocupa un ancho de pista, que es lo que obtienes con la palabra clave auto.

Volviendo a nuestro ejemplo de cinco elementos, me gustaría que el primer elemento vaya en la fila superior y abarque las tres columnas —o en otras palabras, llenar el área correspondiente al encabezado en nuestro boceto.

Las propiedades de posicionamiento se aplican a los elementos de grid que se están colocando.

FIGURA 8. Posicionando un elemento de grid a través de la pista de fila superior en nuestra grid de ejemplo

Una forma de hacer esto es usar las cuatro propiedades de línea inicio/fin e identificar las líneas por sus números, así:

#one {
    grid-row-start: 1;
    grid-row-end: 2;
    grid-column-start: 1;
    grid-column-end: 4;
}

Para grid-row-start, el valor 1 se refiere a la primera línea (superior) del contenedor de grid. Para grid-row-end, el valor 2 se refiere a la línea debajo de la primera pista de fila.

Para grid-column-start, 1 se refiere a la primera línea en el borde izquierdo del contenedor, y el valor 4 para grid-column-end identifica la cuarta y última línea en el borde derecho del contenedor.

Aquí hay una más por si acaso. Esta declaración de estilo posiciona el elemento #four en la columna derecha, como se muestra en la FIGURA 18-10:

#four {
    grid-row-start: 2;
    grid-row-end: 3;
    grid-column-start: 3;
    grid-column-end: 4;
}

NOTA
Si omites una línea de inicio o fin, el área será de una pista de ancho (el valor por defecto, auto).

Usando números de línea negativos

Recuerda cómo las líneas de grid también se numeran en la dirección opuesta, comenzando en -1. Podemos usar eso aquí. Podríamos especificar el grid-column-end para #one como -1, y sería lo mismo que 4. De hecho, este método tiene la ventaja de garantizar abarcar hasta el final de la grid y evita el riesgo de contar mal:

#one {
    grid-row-start: 1;
    grid-row-end: 2;
    grid-column-start: 1;
    grid-column-end: -1;
}

También podríamos usar las líneas nombradas que configuramos aquí. Estos valores de fila son intercambiables con el ejemplo anterior:

#one {
    grid-row-start: header-start;
    grid-row-end: header-end;
    ...
}

Si omites la declaración de línea final, la fila será de una pista de alto (el valor por defecto). En este caso, el área del encabezado es solo de una fila de alto, así que omitir la declaración final sería una forma más de lograr el efecto que queremos.

CONSEJO
Si necesitas abarcar hasta la última línea de grid en una fila o columna, usa el valor -1 y ahórrate algo de conteo. Incluso si el número de filas o columnas cambia en el futuro, -1 siempre seleccionará la última línea, así que no necesitarás renumerar.

El valor span

¿Listo para otra opción más? Podemos decir al elemento en qué línea comenzar, pero en lugar de proporcionar una línea final, podemos usar la palabra clave span para especificar cuántas pistas abarcar. En este ejemplo, el elemento #one comienza en el borde izquierdo de la pista (línea 1) y abarca tres columnas, terminando efectivamente en la línea 4:

#one {
    ...
    grid-column-start: 1;
    grid-column-end: span 3;
}

Los spans también pueden funcionar a la inversa. Si proporcionas solo una línea final, el span busca hacia atrás hacia el inicio de la pista. Los siguientes estilos tienen el mismo efecto que nuestros ejemplos anteriores porque definen el área objetivo por su línea final en el extremo derecho de la grid y abarcan tres columnas hacia el comienzo:

#one {
    ...
    grid-column-start: span 3;
    grid-column-end: -1;
}

El módulo Grid Layout incluye algunos usos más de span que puedes explorar por tu cuenta.

Propiedades de colocación abreviadas

Si cuatro declaraciones se sienten como demasiadas, usa las propiedades abreviadas grid-row y grid-column en su lugar.

grid-row
grid-column
Valores: línea de inicio / línea final
Por defecto: Ver propiedades individuales
Se aplica a: Elementos de grid
Hereda: No

Estas propiedades combinan las propiedades -start y -end en una sola declaración. Los valores de línea de inicio y final se separan por una barra (/). Con la abreviación, puedes acortar cualquiera de los ejemplos anteriores a dos declaraciones. Todas estas reglas hacen lo mismo de diferentes maneras:

#one {
    grid-row: 1 / 2;
    grid-column: 1 / 4;
}

#one {
    grid-row: header-start / header-end;
    grid-column: 1 / -1;
}

#one {
    grid-row: 1 / 2;
    grid-column: span 3 / -1;
}

CONSEJO
Para crear un área de grid que abarque todo el ancho de una grid, usa este atajo útil:

grid-column: 1 / -1

De manera similar, aplicar el valor 1 / -1 a grid-rows crea un área que abarca toda la altura de la grid.

Posicionando Elementos Usando Nombres de Área

Posicionar elementos con líneas de grid es un método robusto y flexible, pero el módulo Grid Layout proporciona otro enfoque que puede ser incluso más intuitivo para algunos propósitos. Solo tienes que estar dispuesto a hacer algo de planificación y configuración interesante por adelantado al configurar la plantilla para la grid.

Asignando áreas de grid nombradas

Además de nombrar líneas de grid, puedes asignar nombres a áreas de la grid. Recuerda que un área de grid está compuesta por una o más celdas en un rectángulo (no formas en L u otras colecciones no rectangulares de celdas). Nombrar áreas de grid es un poco peculiar de implementar, pero proporciona atajos útiles cuando los necesitas.

Para asignar nombres a áreas de grid, usa la propiedad grid-template-areas además de grid-template-rows y grid-template-columns. Todas estas propiedades se aplican al contenedor de grid.

grid-template-areas

Valores: none | serie de nombres de área
Por defecto: none
Se aplica a: Contenedores de grid
Hereda: No

El valor de esta propiedad es una lista de nombres proporcionados para cada celda en la grid, listados fila por fila, con cada fila entre comillas. Cuando las celdas vecinas comparten un nombre, forman un área de grid con ese nombre. Esto se aclarará con un ejemplo.

Como muestra la FIGURA 8, he dado nombres a las áreas en la grid de ejemplo en la que hemos estado trabajando hasta ahora.

FIGURA 8. Cuando las celdas vecinas tienen el mismo nombre, forman un área nombrada a la que se puede hacer referencia más tarde.

En el valor grid-template-areas, hay un nombre de celda para cada una de las nueve celdas tal como aparecen en cada fila (compara el valor con el boceto en la figura). Las listas de celdas de fila no necesitan estar apiladas como lo he hecho aquí, pero muchos desarrolladores encuentran útil alinear las celdas por nombre usando espacios de caracteres para visualizar mejor la estructura de la grid:

#layout {
    display: grid;
    grid-template-rows: [header-start] 100px [content-start] 400px
    [footer-start] 100px;
    grid-template-columns: [ads] 200px [main] 1fr [links] 200px;
    grid-template-areas:
        "header  header  header"
        "ads     main    links"
        "footer  footer  footer";
}

Ten en cuenta que los tamaños de pista aún provienen de las propiedades grid-template-columns y grid-template-rows. La propiedad grid-template-areas simplemente asigna nombres a las áreas, facilitando colocar elementos en ellas más tarde. Si hay tres columnas en la grid, debe haber tres nombres proporcionados para cada fila. Si quieres dejar una celda sin nombre, escribe uno o más puntos (.) en su lugar como marcador de posición para que cada celda siga siendo contabilizada. De nuevo, un boceto de tu grid con las áreas identificadas hará que sea más fácil planificar el valor grid-template-areas.

NOTA
Asegúrate de colocar los nombres de celda de manera que formen rectángulos cuando se combinen para identificar un área nombrada. No formas en L o fragmentos.

En nuestro ejemplo, cuando el navegador ve la palabra “header” tres veces seguidas una al lado de la otra, crea un área equivalente a grid-row: 1 / 2; grid-column: 1 / 4. Las áreas “ads”, “main” y “links” están compuestas por una celda de grid cada una. El área “footer” funciona de manera similar a “header”, pero en la parte inferior de la grid. Asignar nombres a las áreas genera automáticamente nombres de línea de grid vecinas, como se explica en “Nombres de Línea de Grid Bonus”.

Nombres de Línea de Grid Bonus
Cuando das un nombre a un área con grid-template-areas, como beneficio adicional, obtienes un conjunto de nombres de línea de grid generados automáticamente para acompañarlo. Por ejemplo, si nombras un área “main”, las líneas de grid izquierda y superior de esa área se nombran automáticamente “main-start”, y las líneas de grid derecha e inferior se nombran “main-end”. Puedes usar esos nombres de línea al posicionar elementos.
Lo contrario también es cierto. Si asignas explícitamente nombres de línea “portal-start” y “portal-end” alrededor de un área, puedes usar el nombre de área “portal” para asignar un elemento a esa área más tarde, incluso si no lo has definido con grid-template-areas. Puedes mantener el atajo cuando nombras líneas de grid, pero usarlo no es requerido.
Este es un ejemplo principal de la flexibilidad y complejidad del módulo Grid Layout.

Posicionando elementos por nombre de área de grid

Una vez que has configurado los nombres de las áreas de grid, puedes asignar elementos de grid a posiciones por nombre de área usando la propiedad grid-area.

grid-area

Valores: nombre de área | 1 a 4 identificadores de línea
Por defecto: Ver propiedades individuales
Se aplica a: Elementos de grid
Hereda: No

La propiedad grid-area apunta a una de las áreas nombradas con grid-template-areas. También puede apuntar a un nombre de área que se crea implícitamente cuando nombras líneas que delimitan un área con los sufijos “-start” y “-end”, como se menciona en la barra lateral “Nombres de Línea de Grid Bonus”. Con este método, podemos colocar todos los elementos de grid en las áreas que configuramos con nuestra plantilla anterior:

#one   { grid-area: header; }
#two   { grid-area: ads; }
#three { grid-area: main; }
#four  { grid-area: links; }
#five  { grid-area: footer; }

FIGURA 9. Asignando elementos de grid por nombres de área

¡Qué fácil fue eso! Un beneficio de usar áreas es que puedes cambiar la grid, y mientras proporciones áreas de grid nombradas consistentemente, los elementos terminarán en el lugar correcto. No hay necesidad de recordar líneas en la hoja de estilos.

Usando grid-area con números de línea

También puedes usar grid-area para proporcionar una lista de cuatro líneas de grid que definen un área, separadas por barras. El orden en que aparecen es “row-start”, “column-start”, “row-end” y “column-end” (en sentido contrario a las agujas del reloj desde arriba). Hay muchas reglas sobre qué sucede cuando omites valores, pero no vamos a entrar en todos esos puntos más finos aquí (puedes consultar la especificación). La declaración grid-area para el primer elemento de grid podría escribirse así para lograr el mismo resultado que los ejemplos anteriores:

#one {
    grid-area: 1 / 1 / 2 / 4;
    /* row-start / column-start / row-end / column-end */
}
