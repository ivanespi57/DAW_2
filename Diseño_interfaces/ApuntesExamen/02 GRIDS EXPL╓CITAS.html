GRIDS EXPLÍCITAS

En los ejemplos de grid implícita, configuramos algunos anchos de columna y dejamos que el navegador haga el resto. Ahora veremos cómo especificar un número de filas y columnas, creando así una grid explícita. La mayor parte de esta sección se dedicará a revisar las muchas opciones disponibles para establecer el tamaño de las pistas.

Las grids explícitas se utilizan a menudo para crear la estructura de alineación de una página completa, por lo que en esta sección trabajaremos en una grid que tiene áreas para un encabezado, contenido principal, dos barras laterales y un pie de página (ver Nota). Me gusta hacer un boceto rápido de cómo quiero que se vea la grid final (FIGURA 18-10). Un boceto es un buen primer paso para trabajar con grids. A partir de mi boceto, puedo ver que el diseño requiere tres pistas de fila y tres pistas de columna, aunque algunas de las áreas de contenido eventualmente se extenderán sobre más de una celda.

Definiendo Pistas de Grid

Para configurar la grid, especifica la altura de cada fila y el ancho de cada columna con las propiedades de plantilla, grid-template-rows y grid-template-columns, que se aplican al elemento contenedor.

  • grid-template-columns

Por defecto: none

Hereda: No

El valor de la propiedad grid-template-rows es una lista de las alturas para cada pista de fila en la grid. El valor de grid-template-columns es una lista de los anchos para cada pista de columna. Como ya has visto en ejemplos en este capítulo, el número de tamaños de pista proporcionados determina el número de filas o columnas. Por ejemplo, si proporcionas cuatro longitudes para grid-template-columns, obtienes una grid que inicialmente se divide en cuatro columnas.

Siguiendo con nuestro ejemplo de grid de cinco elementos, he añadido propiedades de plantilla para dividir el contenedor #layout en tres columnas y tres filas con las dimensiones en píxeles que designé en el boceto original (FIGURA 18-11):

#layout {
    display: grid;
    grid-template-rows: 100px 400px 100px;
    grid-template-columns: 200px 500px 200px;
}

Veamos qué sucede si hacemos una verificación rápida de la grid hasta ahora en el navegador. Como se esperaba, los elementos de la grid fluyen secuencialmente hacia las celdas de grid disponibles (FIGURA 18-11). La imagen de la derecha revela la estructura de grid subyacente, que no se vería cuando la grid se muestra en el navegador.

Debido a que solo hay cinco elementos hijos en el div #layout, solo se llenan las primeras cinco celdas, y la tercera fila permanece vacía. Vale la pena señalar que la estructura establecida para grids explícitas es independiente del número de elementos en el contenedor. En este ejemplo, el navegador llenó las primeras cinco de las nueve celdas, pero (como puedes ver cuando se revela la estructura) preservó el resto. Si tienes un diseño que usa una grid de 24 celdas, podrías colocar deliberadamente solo unos pocos elementos en la grid, dejando las celdas restantes como “espacio en blanco”. Esa es la belleza del diseño de grid.

FIGURA 12. Por defecto, los elementos de grid fluyen hacia las celdas de grid por filas.

Si el número de elementos excede el número de celdas en la grid (por ejemplo, si hubiera habido 14 elementos hijos en nuestro div #layout en lugar de 5), ¿puedes adivinar qué sucede? El algoritmo de grid añadirá tantas filas nuevas como sea necesario hasta que cada último elemento esté colocado. Las filas añadidas se dimensionan según el valor grid-auto-rows, si se proporciona; de lo contrario, serán tan altas como sea necesario para acomodar el contenido. Puedes encontrarte con escenarios en los que una grid explícita con una grid implícita que se extiende desde ella es una característica deseada. Por ahora, ten en cuenta que si no hiciste suficientes celdas para tu contenido, el navegador lo hará por ti.

Especificando Valores de Tamaño de Pista

Todos los tamaños de pista en el ejemplo anterior se especificaron en longitudes de píxeles directas, pero los tamaños fijos son solo una de muchas opciones de tamaño de pista. El módulo Grid Layout proporciona un montón de formas de especificar tamaños de pista, incluyendo valores antiguos conocidos como unidades de longitud CSS (por ejemplo, píxeles, rems, o ems) y valores porcentuales, así como algunos valores específicos de grid, incluyendo:

• La unidad fraccional (fr)
• La función repeat()
• La función minmax()
• Valores basados en contenido: auto, min-content, max-content (ver Nota)

Unidades fraccionarias (fr)

Usaste un valor fr en el EJERCICIO 18-1, pero merece un poco más de explicación. La unidad fraccional específica de grid (fr) permite a los autores crear anchos de pista que se expanden y contraen dependiendo del espacio disponible, similar a la propiedad flex-grow para Flexbox.

Volviendo a nuestro ejemplo de grid explícita, si cambiamos el ancho de la columna del medio de 500px a 1fr, el navegador asigna todo el espacio sobrante (después de que se acomodan las pistas de columna de 200 píxeles) a esa pista de columna. La columna del medio ahora se flexiona para adaptarse al ancho disponible del viewport (FIGURA 18-12):

#layout {
    display: grid;
    grid-template-rows: 100px 400px 100px;
    grid-template-columns: 200px 1fr 200px;
}

NOTA
La función fit-content() también basa el tamaño de pista en el contenido, pero no la cubriré en este capítulo. Consulta la especificación (w3.org/TR/css-grid-2/) para más detalles.

Valores de Tamaño de Pista

La especificación Grid Layout permite los siguientes valores para las propiedades grid-template-*:

• Unidades de longitud CSS (como px, em, o rem)
• Valores porcentuales (%)
• Unidades fraccionarias (fr)
• repeat()
• minmax()
• auto
• min-content, max-content
• fit-content()

FIGURA 14. Cuando la columna del medio tiene un tamaño de pista de 1fr, ocupa el espacio restante en la ventana del navegador y se flexiona para adaptarse al ancho del navegador.

La unidad fr es excelente para combinar anchos de pista fijos y flexibles, pero también podríamos usar todas las unidades fr para dar a todas las columnas anchos proporcionales. Cuando hay múltiples pistas con unidades fr, el navegador suma las unidades y divide el espacio disponible en esa cantidad de porciones. Las porciones se asignan según el número de unidades especificadas. Por ejemplo, todos los anchos de columna en la siguiente muestra de grid se flexionan según el ancho del navegador disponible, pero la columna del medio siempre será el doble del ancho de las columnas laterales:

grid-template-columns: 1fr 2fr 1fr;

Rango de tamaño mínimo y máximo

Otro valor útil para los tamaños de pista es la función minmax(), que proporciona flexibilidad pero te permite establecer límites. Puedes restringir el rango de tamaño de una pista estableciendo sus anchos mínimo y máximo usando la función minmax() en lugar de un tamaño de pista específico. Los tamaños de pista mínimo y máximo (en ese orden) se colocan dentro de paréntesis, separados por una coma:

grid-template-columns: 200px minmax(10em, 30em) 200px;

Esta regla establece la columna del medio a un ancho que es al menos 10em pero nunca más ancho que 30em.

ADVERTENCIA
Las unidades fr no están permitidas como valor mínimo en una declaración minmax().

Repitiendo tamaños de pista

Digamos que tienes una grid que tiene 10 columnas con anchos de columna alternos, como esto:

grid-template-columns: 20px 1fr 20px 1fr 20px 1fr 20px 1fr 20px 1fr;

Eso es un poco pesado de escribir (lo sé, acabo de hacerlo), así que la gente del W3C ha proporcionado un atajo útil en forma de la función repeat(). En el ejemplo anterior, el patrón “20px 1fr” se repite cinco veces, lo que se puede escribir como sigue:

grid-template-columns: repeat(5, 20px 1fr);

Mucho mejor, ¿no? El primer número indica el número de repeticiones, y los tamaños de pista después de la coma proporcionan el patrón. Puedes usar la función repeat() en una secuencia más larga de tamaños de pista—por ejemplo, si esas 10 columnas estuvieran intercaladas entre dos columnas de 200 píxeles de ancho al inicio y al final:

grid-template-columns: 200px repeat(5, 20px 1fr) 200px;

Podríamos haber usado la función repeat() en el paso 4 del EJERCICIO 18-1 para simplificar la lista de alturas de pista de fila (mira hacia atrás para comparar):

dl {
    display: grid;
    grid-auto-flow: column;
    grid-auto-rows: repeat(3, 3em 1fr);
    gap: .5em;
}

ADVERTENCIA
Solo puedes usar una notación repeat() para una declaración dada. Puedes usar minmax() dentro de repeat(), pero las unidades fr y las palabras clave basadas en contenido solo pueden usarse como valor máximo.

Dimensionado basado en contenido

Los valores min-content, max-content, y auto dimensionan la pista basándose en el tamaño del contenido dentro de ella. La FIGURA 15 muestra el resultado de usar min-content y max-content para una celda que contiene texto.

FIGURA 15. Los valores de dimensionado de pista min-content y max-content

min/max-content

El valor min-content es el más pequeño que puede obtener la pista sin desbordarse (por defecto, a menos que sea anulado por un min-width explícito). Es equivalente al “bit más grande no rompible de contenido”—en otras palabras, el ancho de la palabra más larga o imagen más ancha. Es poco probable que sea útil para elementos que contienen párrafos normales, pero puede ser útil en algunos casos donde no quieres que la pista sea más grande de lo que necesita ser. Este ejemplo establece tres columnas, con la columna de la derecha dimensionada justo lo suficientemente ancha para contener la palabra más larga o imagen:

grid-template-columns: 50px 1fr min-content;

La propiedad max-content permite la cantidad máxima de espacio necesario para el contenido, incluso si eso significa extender la pista más allá de los límites del contenedor de grid. Cuando se usa como ancho de columna, la pista de columna será lo suficientemente ancha para acomodar el contenido más ancho en esa pista sin ajuste de línea. Eso significa que si el contenido es un párrafo, la pista será lo suficientemente ancha para contener todo el texto en una línea. Esto hace que max-content sea más apropiado para frases cortas o elementos de navegación cuyo texto no quieres que se ajuste (aunque auto puede funcionar mejor, porque permite el ajuste si no hay suficiente espacio).

La palabra clave auto

Usar la palabra clave auto para un tamaño de pista es básicamente como entregar las llaves al navegador. En general, hace que la pista se dimensione lo suficientemente grande para acomodar su contenido, mientras toma en consideración qué otras restricciones están en su lugar. Si quieres dimensionar una pista basándose en su contenido, pero no estás seguro de qué palabra clave usar, comienza con auto.

Si quieres dimensionar una pista basándose en su contenido, pero no estás seguro de qué palabra clave usar, comienza con auto.

Como palabra clave por sí sola, funciona de manera similar a minmax(min-content, max-content), permitiendo que la pista sea tan estrecha como puede ser sin que nada se desborde pero crezca para ajustarse a su contenido sin ajuste si hay suficiente espacio.

Cuando usas la palabra clave auto en la función minmax(), se comporta de manera muy similar a min-content o max-content, dependiendo de si la pones en la ranura mínima o máxima. Un valor máximo auto permite que se añada espacio extra a la pista basándose en configuraciones de alineación (no el caso para max-content). Como mínimo, usa el min-width o min-height especificado de un elemento (si hay alguno) en lugar de su tamaño min-content.

Una Breve Introducción a subgrid

Anteriormente en el capítulo, señalé que solo los hijos directos de un contenedor de grid se convierten en elementos de grid. Es posible hacer que un elemento hijo se muestre como una grid también, creando así una grid anidada dentro de una grid, pero hacer eso solo no hace que las pistas del elemento hijo se alineen con las de su padre. Para lograr eso, el Módulo CSS Grid Layout Nivel 2 introdujo el valor subgrid, que aplica las medidas de pista de la grid padre al elemento de grid anidado.

Para usarlo, primero haz que el elemento hijo se muestre como una grid (display: grid). Si quieres que la grid anidada use las mismas pistas de columna que su padre, establece la propiedad grid-template-columns a subgrid, y heredará esos anchos. Similarmente, si quieres que la grid anidada siga la alineación de pista del padre, usa subgrid como valor para grid-template-rows. Con subgrid, la grid anidada hereda cualquier espacio entre pistas establecido con la propiedad gap también.

La historia completa sobre usar subgrid requiere más discusión de la que tengo espacio aquí, pero puedes ponerte al día con el excelente artículo de referencia en MDN Web Docs (oreil.ly/7n8Xr). También encontrarás un número de buenos tutoriales en video en YouTube.

Las subgrids son una de las adiciones más recientes al conjunto de herramientas de Grid Layout, por lo que el soporte del navegador es un poco menos extendido que para otras propiedades. Asegúrate de consultar CanIUse.com para estadísticas de soporte de navegador actualizadas.
