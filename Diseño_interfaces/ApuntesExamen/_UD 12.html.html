ALINEANDO ELEMENTOS CON FLEXBOX

Hasta ahora hemos visto cómo mover elementos usando alineación de texto, flotantes y posicionamiento. Durante décadas estas fueron nuestras únicas opciones, y aunque funcionaban, los diseñadores web estábamos listos para una mejor solución. Aquí entra el Módulo de Diseño de Caja Flexible de CSS, o Flexbox para abreviar.

En pocas palabras, Flexbox se usa para organizar elementos en una fila o columna, pero también nos da un control más preciso sobre la alineación y resuelve algunas de las limitaciones frustrantes de nuestras herramientas de diseño anteriores. Una de las grandes maravillas del modelo Flexbox es que los elementos se redimensionan, o flex usando el término formal, para ajustarse al espacio disponible. Esto significa que permite a los elementos estirarse o encogerse dentro de sus contenedores, evitando el espacio desperdiciado y el desbordamiento—una ventaja real para hacer diseños que se adapten a una variedad de tamaños de ventana. Otras ventajas incluyen:

• La capacidad de hacer que todos los elementos vecinos tengan la misma altura

• Centrado horizontal y vertical fácil (curiosamente esquivo con los métodos CSS antiguos)

• La capacidad de cambiar el orden en que se muestran los elementos, independientemente de su orden en el código fuente

Flexbox es ideal para elementos de página que necesitan alinearse de alguna manera. Las aplicaciones prácticas incluyen barras de navegación, galerías, listados de productos y elementos de formulario-

El modelo de diseño Flexbox es increíblemente robusto, pero como fue diseñado para máxima flexibilidad, puede tomar un poco de tiempo acostumbrarse. Aquí tienes una forma útil de pensar en él mientras nos adentramos en este capítulo: cuando le dices a un elemento que se convierta en un flexbox, todos sus elementos hijos se alinean en un eje, como cuentas en un hilo. CONFIGURANDO UN CONTENEDOR FLEX

Ya has aprendido sobre el modo de visualización en bloque para apilar elementos en el flujo normal y el modo en línea para mostrar contenido horizontalmente. Flexbox es otro modo de visualización con sus propios comportamientos.

Para activar el modo Flexbox para un elemento, establece su propiedad display a flex o inline-flex (ver Nota). Ahora es un contenedor flex, y todos sus elementos hijos directos (ya sean divs, elementos de lista, párrafos, etc.) automáticamente se comportan como elementos flex en ese contenedor. Los elementos flex se disponen y alinean a lo largo del eje, que puede aparecer en una línea o envolver a múltiples líneas.

El ejemplo 11.1 muestra el efecto de simplemente agregar display: flex a un div, activando así el interruptor Flexbox.

EL HTML

<div id="container">
    <div class="box box1">1</div>
    <div class="box box2">2</div>
    <div class="box box3">3</div>
    <div class="box box4">4</div>
    <div class="box box5">5</div>
</div>

LOS ESTILOS

#container {
    display: flex;
}

Por defecto, los divs se muestran como elementos de bloque, apilándose verticalmente. Activar el modo Flexbox los hace alinearse en una fila.
Al aplicar el modo de visualización flex al contenedor convierte sus elementos hijos en elementos flex que se alinean a lo largo de un eje. No necesitas hacer nada a los elementos hijos en sí mismos.

Controlando el “Flujo” Dentro del Contenedor

Puedes ver que los elementos se han alineado en una fila de izquierda a derecha, que es el comportamiento predeterminado de Flexbox si tu página está en inglés u otro idioma escrito en filas de izquierda a derecha. Esto es porque la dirección predeterminada de Flexbox coincide con la dirección del idioma en que está escrita la página. Iría de derecha a izquierda por defecto en hebreo o árabe, o en columnas si la página está escrita en un sistema de escritura vertical.

Vale la pena señalar que puedes convertir cualquier elemento flex en un contenedor flex estableciendo su propiedad display a flex, resultando en un flexbox anidado.

DATOS CURIOSOS DE FLEXBOX

Aquí tienes algunas cosas que debes saber sobre el comportamiento de Flexbox y los elementos flex:

• float, clear, diseño multicolumna, y vertical-align no
funcionan con elementos en modo Flexbox.

• Los márgenes no colapsan en modo Flexbox. Los bordes de margen de los elementos se colocan al inicio o final de la línea flex y no se superponen con el padding del contenedor. Los márgenes en elementos vecinos se suman.

• La especificación recomienda evitar valores de porcentaje para
márgenes y padding en elementos flex debido a resultados > impredecibles.

Una vez que conviertes un elemento en un contenedor flex, hay algunas propiedades que puedes establecer en ese contenedor para controlar cómo fluyen los elementos dentro de él. El flujo se refiere a la dirección en que se disponen los elementos flex así como si se les permite envolver a líneas adicionales.

Especificando la Dirección del Flujo

Puede que estés contento con que los elementos se alineen en una fila por defecto, pero hay algunas otras opciones que se controlan con la propiedad flex-direction.

flex-direction

Valores: row | column | row-reverse | column-reverse

Predeterminado: row

Se aplica a: Contenedores flex

Hereda: No

El valor predeterminado es row, como vimos en el ejemplo anterior (ver la barra lateral “Dirección de Fila y Columna” para una aclaración importante). También puedes especificar que los elementos se alineen verticalmente en una column. Las otras opciones, row-reverse y column-reverse, también organizan elementos horizontal y verticalmente, como esperarías, pero empiezan llenando desde el extremo opuesto. El Ejemplo 11.2 muestra los efectos de cada palabra clave aplicada a nuestro ejemplo simple.

Dirección de Fila y Columna

En sistemas de escritura con líneas horizontales de texto, la palabra clave row dispone elementos horizontalmente, que es como los occidentales típicamente pensamos en una “fila” orientada. Ten en cuenta que en idiomas orientados verticalmente, row alinea elementos verticalmente, manteniéndose con la dirección predeterminada del sistema de escritura. De manera similar, column resulta en elementos alineados horizontalmente en idiomas verticales.

Este es un comportamiento que vale la pena conocer; sin embargo, como estamos creando sitios en inglés en este libro, seguiré la suposición de que row = horizontal y column = vertical a lo largo de este capítulo por simplicidad.

flex-direction: row; (predeterminado)

flex-direction: row-reverse;

flex-direction: column;

flex-direction: column-reverse;

Ahora que has visto Flexbox en acción, es buen momento para familiarizarte con la terminología formal de Flexbox. Como el sistema es agnóstico de dirección, no hay referencias a ubicaciones físicas como “izquierda”, “derecha”, “arriba” o “abajo” en los valores de propiedad. En su lugar, hablamos del eje principal y el eje cruzado.

El eje principal es la dirección de flujo que has especificado para el contenedor flex. Para idiomas principalmente horizontales, cuando flex-direction se establece a row, el eje principal es horizontal; para column, el eje principal es vertical (otra vez, las filas y columnas dependen del idioma). El eje cruzado es la dirección que sea perpendicular al eje principal.

Además de los ejes, entender las otras partes del sistema Flexbox hace que las propiedades sean más fáciles de aprender. Tanto el eje principal como el cruzado tienen un inicio y un final, basados en la dirección en que fluyen los elementos. Ten en cuenta que la especificación Flexbox usa los términos lógicos “start” y “end” para que funcione con todas las direcciones de escritura.

El tamaño principal es el ancho (o altura si es una columna) del contenedor a lo largo del eje principal, y el tamaño cruzado es la altura (o ancho si es una columna) a lo largo del eje cruzado.

Envolvimiento a Múltiples Líneas

Si tienes un número grande o desconocido de elementos flex en un contenedor y no quieres que todos se compriman en el espacio disponible, puedes permitir que se dividan en líneas adicionales con la propiedad flex-wrap.

flex-wrap

Valores: nowrap | wrap | wrap-reverse

Predeterminado: nowrap

Se aplica a: Contenedores flex

Hereda: No

Por defecto, los elementos hacen lo que se comprime y no se envuelven a líneas adicionales (nowrap). La palabra clave wrap activa la capacidad de envolver a múltiples líneas. Las nuevas líneas se agregan en la dirección desde cross start hasta cross end. Por ejemplo, con el flex-direction predeterminado de row, las nuevas líneas se posicionan desde arriba hacia abajo, que es lo que

wrap-reverse divide los elementos en múltiples líneas pero los fluye en la dirección opuesta, desde cross end hasta cross start (desde abajo hacia arriba, en este caso). Se siente un poco esotérico, pero nunca sabes cuándo podría surgir una ocasión para usarlo.

He agregado más divs a nuestro ejemplo de flexbox numerado y he dado a los elementos flex un ancho del 25% para que solo cuatro quepan a lo ancho del contenedor.

EL HTML

<div id="container">
    <div class="box box1">1</div>
    <!-- 8 more boxes here -->
    <div class="box box10">10</div>
</div>

LOS ESTILOS

#container {
    display: flex;
    flex-direction: row;
    flex-wrap: wrap;
}
.box {
    width: 25%;
}

flex-wrap: wrap;

flex-wrap: wrap-reverse;

flex-wrap: nowrap; (predeterminado)

Cuando el envolvimiento está deshabilitado, los elementos flex se comprimen para ajustarse a la ventana. Si no hay suficiente espacio, los elementos pueden cortarse.

Por defecto, cuando flex-direction se establece a column, el contenedor se expande para contener la altura de los elementos. Para ver el envolvimiento en acción, necesitas establecer una altura en el contenedor, como he hecho en el siguiente ejemplo. El ejemplo 11-4b muestra cómo funciona el envolvimiento para cada una de las palabras clave flex-wrap cuando flex-direction se establece a column.

#container {
    display: flex;
    height: 350px;
    flex-direction: column;
    flex-wrap: wrap;
}
.box {
    width: 25%;
}

Juntándolo con flex-flow

La propiedad abreviada flex-flow hace que especificar flex-direction y flex-wrap sea corto y dulce. Omitir un valor resulta en el valor predeterminado para su respectiva propiedad, lo que significa que puedes usar flex-flow para cualquiera o ambas direcciones y envolvimiento.

flex-flow

Valores: flex-direction flex-wrap

Predeterminado: row nowrap

Se aplica a: Contenedores flex

Hereda: No

Usando flex-flow, podría acortar el ejemplo anterior así:

#container {
    display: flex;
    height: 350px;
    flex-flow: column wrap;
}

CONTROLANDO LA ALINEACIÓN DE ELEMENTOS FLEX

Hasta ahora, has visto cómo activar el modo Flexbox, convirtiendo un elemento en un contenedor flex y sus hijos en elementos flex. También has aprendido cómo cambiar la dirección en que fluyen los elementos y permitir que se envuelvan a múltiples líneas. Las propiedades restantes del contenedor afectan la alineación de elementos a lo largo del eje principal (justify-content) y el eje cruzado (align-items y align-content). Ver la barra lateral “El Módulo de Alineación de Cajas” para un poco de información de fondo sobre cómo el W3C está pensando en estas propiedades de alineación.

Alineación en el Eje Principal

Por defecto, los elementos flex son solo tan anchos como necesitan ser para contener el contenido de los elementos, lo que significa que el contenedor puede tener espacio de sobra en la línea flex. También por defecto, los elementos fluyen uno junto al otro desde el “main start” (basado en la dirección del idioma y la dirección de la línea flex).

La propiedad justify-content define cómo se debe distribuir el espacio extra alrededor o entre elementos que son inflexibles o han alcanzado su tamaño máximo (ver Nota). La configuración se aplica después de que se han calculado los márgenes en los elementos y después de que se han contabilizado los valores “flex”. Si los elementos están especificados para crecer y llenar el ancho del contenedor, entonces justify-content no es aplicable.

justify-content

Valores: flex-start | flex-end | center | space-between | space-around

Predeterminado: flex-start

Se aplica a: Contenedores flex

Hereda: No

Aplicas justify-content al elemento contenedor flex porque controla el espaciado dentro del contenedor mismo:

#container {
    display: flex;
    justify-content: flex-start;
}

Como esperarías, flex-start y flex-end posicionan la línea de elementos hacia el inicio y final del eje principal, respectivamente, y center los centra.

space-between y space-around requieren un poco más de explicación. Cuando justify-content se establece a space-between, el primer elemento se posiciona en el punto de inicio, el último elemento va al punto final, y el espacio restante se distribuye uniformemente entre los elementos restantes. La propiedad space-around agrega una cantidad igual de espacio en el lado izquierdo y derecho de cada elemento, resultando en una duplicación del espacio entre elementos vecinos. La FIGURA 12-8 muestra cómo se alinean los elementos usando cada uno de los valores de palabra clave para justify-content.

Cuando la dirección del contenedor flex se establece a column con un eje principal vertical, las palabras clave funcionan de la misma manera; sin embargo, necesita haber una altura explícita del contenedor con espacio sobrante para que veas el efecto. He cambiado el tamaño del texto y establecido una altura en el elemento contenedor en la FIGURA 12-9 para demostrar las mismas palabras clave aplicadas a un eje principal vertical cuando flex-direction se establece a column.

El Módulo de Alineación de Cajas

El W3C ha creado un módulo separado documentando todas las
características relacionadas con la alineación de cajas dentro de sus
contenedores. El Módulo de Alineación de Cajas CSS Nivel 3 define los
conceptos de ejes principal y cruzado y especifica seis propiedades de
alineación de cajas que se aplican a Flexbox así como a los modelos de
diseño de bloque, cuadrícula y tabla. Además, introduce propiedades de
espaciado que controlan la cantidad de espacio entre filas y columnas
que pueden aplicarse a diseños flex, cuadrícula y multicolumna.
Cubriré el concepto de “gap” con más detalle mas adelante.

Por ahora, las propiedades de alineación también están incluidas en el
módulo Flexbox, pero el plan a largo plazo es usar el Módulo de

espacio disponible. Ese es el trabajo de las propiedades flex, que

Alineación en el Eje Cruzado

Eso se encarga de organizar las cosas en el eje principal, pero también puedes querer jugar con la alineación en el eje cruzado (arriba y abajo cuando la dirección es row, izquierda y derecha si la dirección es column). La alineación y estiramiento del eje cruzado son trabajo de la propiedad align-items.

align-items

Valores: flex-start | flex-end | center | baseline | stretch

Predeterminado: stretch

Se aplica a: Contenedores flex

Hereda: No

He demostrado los varios valores de palabra clave para align-items como se aplican a filas en la FIGURA 12-10. Para ver el efecto, debes especificar una altura para el contenedor; de lo contrario, se expande lo justo para contener el contenido sin espacio extra que sobrar. He dado al contenedor una altura fija aquí para mostrar cómo se posicionan los elementos en el eje cruzado (es decir, verticalmente en relación al contenedor) con los diferentes valores.

Como justify-content, la propiedad align-items se aplica al contenedor flex (eso puede ser un poco confuso porque “items” está en el nombre):

#container {
    display: flex;
    flex-direction: row;
    height: 200px;
    align-items: flex-start;
}

Los valores flex-start, flex-end, y center deberían ser familiares, solo que esta vez se refieren al inicio, final y centro del eje cruzado. El valor baseline alinea las líneas base de las primeras líneas de texto, independientemente de su tamaño. Puede ser una buena opción para alinear elementos con diferentes tamaños de texto, como títulos y párrafos a través de múltiples elementos. Finalmente, stretch, que es el predeterminado, hace que los elementos se estiren hasta que llenen el eje cruzado (es decir, la altura del contenedor).

Cuando la dirección del contenedor flex se establece a column, align-items alinea elementos horizontalmente en el contenedor. Mira las FIGURAS 12-3 y 12-9, y verás que cuando establecí los elementos en una columna y no proporcioné ninguna información de alineación, cada elemento se estiró al ancho completo del eje cruzado, porque stretch es el valor predeterminado.

Si te gustaría que uno o más elementos específicos anulen la configuración del eje cruzado, usa la propiedad align-self en los elementos individuales. Esta es la primera propiedad que hemos visto que se aplica a un elemento, no al contenedor. align-self usa los mismos valores que align-items; simplemente funciona en un elemento a la vez.

align-self

Valores: flex-start | flex-end | center | baseline | stretch

Predeterminado: stretch

Se aplica a: Elementos flex

Hereda: No

En el siguiente código y FIGURA 12-11, la cuarta caja está configurada para alinearse al final del eje cruzado, mientras que las otras tienen el comportamiento de estiramiento predeterminado:

.box4 {
    align-self: flex-end;
}

FIGURA 12-11. Usa align-self para hacer que un elemento anule la alineación del eje cruzado de su contenedor.

Alineando Múltiples Líneas

La opción final de alineación, align-content, afecta cómo se distribuyen múltiples líneas flex a través del eje cruzado. Esta propiedad se aplica solo cuando flex-wrap se establece a wrap o wrap-reverse y hay múltiples líneas para alinear. Si los elementos están en una sola línea, no hace nada.


align-content

Valores: flex-start | flex-end | center | space-around | space-between | stretch

Predeterminado: stretch

Se aplica a: Contenedores flex multilínea

Hereda: No


align-content se aplica solo cuando hay múltiples líneas flex envueltas.

Todos los valores que ves en la lista de propiedades deberían parecer familiares, y funcionan de la manera que esperarías. Esta vez, sin embargo, se aplican a cómo se distribuye el espacio extra alrededor de múltiples líneas en el eje cruzado, como se muestra en la FIGURA 12-12.

Nuevamente, la propiedad align-content se aplica al elemento contenedor flex. Se requiere una altura para el contenedor también, porque sin ella el contenedor sería justo lo suficientemente alto para acomodar el contenido y no habría espacio sobrante. Para las opciones de alineación mostradas en la FIGURA 12-12, le di al contenedor una altura de 350px y permití que las líneas se envolvieran:

#container {
    display: flex;
    flex-direction: row;
    flex-wrap: wrap;
    height: 350px;
    align-content: flex-start;
}

.box {
    width: 25%;
}

TÉCNICAS DE ALINEACIÓN FLEXBOX

Solo hemos cubierto las propiedades del contenedor flex, y resulta que ya tienes suficiente conocimiento de Flexbox para abordar dos métodos populares para usar Flexbox en alineación. En la primera técnica, aplicamos un margen a un elemento flex para separarlo de los otros elementos en el eje. La segunda técnica usa Flexbox para centrar perfectamente un elemento dentro de su elemento contenedor.

Alineando Elementos con Márgenes

Las barras de menú son ubicuas en la web, y es común que un elemento en la barra, como un logo o un campo de búsqueda, se separe visualmente de los otros. Puedes usar un margen para poner el espacio extra del contenedor en un lado específico o lados de un elemento flex, separando así ese elemento. Esto debería quedar más claro con un ejemplo.

El menú en la FIGURA 12-13 tiene un logo y cuatro opciones de menú. Me gustaría que el logo permanezca en la esquina izquierda pero que las opciones aparezcan a la derecha, independientemente del ancho de la ventana.

EL HTML

<ul>
    <li class="logo"><img src="logo.png" alt="LoGoCo"></li>
    <li>About</li>
    <li>Blog</li>
    <li>Shop</li>
    <li>Contact</li>
</ul>

LOS ESTILOS

ul {
    display: flex;
    align-items: center;
    background-color: #00af8f;
    list-style: none; /* removes bullets */
    padding: .5em;
    margin: 0;
}
li {
    margin: 0 1em;
}
li.logo {
    margin-right: auto;
}

Usando un margen para ajustar el espacio alrededor de elementos flex. En este ejemplo, el margen derecho del elemento logo empuja los elementos restantes hacia la derecha.

Técnicas de Alineación Flexbox

He convertido la lista no ordenada (ul) en un contenedor flex, por lo que sus elementos de lista (li) ahora son elementos flex. Por defecto, los elementos se mantendrían juntos al inicio del eje principal (a la izquierda) con el espacio extra a la derecha. Establecer el margen derecho del elemento logo a auto mueve el espacio extra a la derecha del logo, empujando los elementos restantes hasta el final (el “main end”).

Esta técnica se aplica a varios escenarios. Si quieres que solo el último elemento aparezca a la derecha, establece su margen izquierdo a auto. ¿Quieres espacio igual alrededor del elemento central en una lista? Establece tanto sus márgenes izquierdo como derecho a auto. ¿Quieres empujar un botón al fondo de una columna? Establece el margen superior del último elemento a auto. El espacio extra en el contenedor va al margen y empuja los elementos vecinos. Nota, sin embargo, que cuando aplicas margin: auto a un elemento flex, la propiedad justify-content (si hay una) ya no tiene un efecto visual, porque has asignado manualmente una ubicación para el espacio extra en el eje principal.

Centrando Elementos con Flexbox

Puede que te sorprenda saber que CSS realmente no tenía una forma explícita de centrar elementos verticalmente hasta que llegó Flexbox. Claro, se nos ocurrieron soluciones alternativas, pero fue un alivio para nosotros los veteranos tener una solución simple y correcta.

En el siguiente ejemplo, he centrado un div que contiene una sola imagen en un div contenedor más grande usando propiedades de alineación Flexbox con el valor de palabra clave center . ¡Realmente no podría ser más simple, y sin embargo esperamos años y años para esto!

EL HTML

<div class="container">
    <div class="item"><img src="flower.png" alt="photo of a yellowflower"></div>
</div>

LOS ESTILOS

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    width: 400px;
    height: 400px;
    background: blanchedalmond;
}
.item {
    width: 100px;
    height: 100px;
}

DETERMINANDO CÓMO LOS ELEMENTOS “FLEX” EN EL CONTENEDOR

Por fin, hemos llegado a la propiedad importante que le da su nombre a Flexbox. Como se mencionó al principio del capítulo, la característica principal del modelo Flexbox es que los elementos pueden flex (redimensionarse) para llenar el espacio disponible en el contenedor. En esta sección, conocerás las propiedades flex.

Anteriormente, aprendiste sobre la propiedad justify-content, que distribuye espacio extra en el contenedor entre y alrededor de elementos a lo largo del eje principal. El concepto de flex se refiere a cómo se distribuye el espacio dentro de los elementos mismos, haciéndolos crecer o encogerse según sea necesario para ajustarse al espacio disponible.

Flex se controla con la propiedad flex, que especifica cuánto puede crecer y encogerse un elemento, e identifica su tamaño inicial. La historia completa es que flex es una propiedad abreviada para flex-grow, flex-shrink, y flex-basis, pero la especificación recomienda encarecidamente que los autores usen la abreviada flex en lugar de propiedades individuales para evitar valores predeterminados conflictivos y para asegurar que los autores consideren los tres aspectos de flex para cada instancia.

flex

Valores: none | flex-grow flex-shrink flex-basis

Predeterminado: 0 1 auto

Se aplica a: Elementos flex

Hereda: No

El valor para la propiedad flex son típicamente valores para las tres propiedades flex, listados en este orden:

flex: flex-grow flex-shrink flex-basis;

Para las propiedades flex-grow y flex-shrink, los valores 1 y 0 funcionan como interruptores de encendido/apagado, donde 1 “activa” el comportamiento, permitiendo que un elemento crezca o se encoja, y 0 lo previene. La propiedad flex-basis establece las dimensiones iniciales, ya sea a un tamaño específico o a un tamaño basado en el contenido.

Para mostrarte cómo funciona esto, aquí hay un ejemplo rápido en el que un elemento de lista comienza con 200 píxeles de ancho (su flex-basis), se le permite expandirse para llenar espacio extra (flex-grow establecido a 1), pero no se le permite encogerse (flex-shrink establecido a 0) más estrecho que los 200 píxeles originales:

li {
    flex: 1 0 200px;
}

Eso debería darte la idea general. En esta sección, echaremos un vistazo mucho más cercano al crecimiento, encogimiento y tamaño base, en ese orden. Las propiedades flex, aunque fáciles de usar, son un poco tediosas de explicar, así que respira profundo mientras nos adentramos en los detalles.

Primero, es importante señalar que flex y sus propiedades componentes se aplican a elementos flex, no al contenedor. Mantener el control de qué propiedades van en el contenedor y cuáles van en los elementos es uno de los trucos de usar Flexbox. Ver la barra lateral “Propiedades Flex” para una lista práctica de cómo se dividen las propiedades.

Expandiendo Elementos (flex-grow)

El primer valor en la propiedad flex especifica si (y en qué proporción) un elemento puede estirarse más grande—en otras palabras, su valor flex-grow (ver Nota). Por defecto se establece a 0, lo que significa que un elemento no tiene permitido crecer más ancho que el tamaño de su contenido o su ancho especificado.

flex-grow

Valores: number

Predeterminado: 0

Se aplica a: Elementos flex

Hereda: No

Si estableces el valor flex-grow para todos los elementos en un contenedor a 1, el navegador toma cualquier espacio extra que esté disponible a lo largo del eje principal y lo aplica igualmente a cada elemento, permitiendo que todos se estiren la misma cantidad.

Tomemos el ejemplo de caja simple de antes en el capítulo y veamos cómo se comporta con varias configuraciones flex aplicadas. La FIGURA 12-19 muestra qué pasa cuando flex-grow se establece a 1 para todos los elementos de caja (flex-shrink y flex-basis se dejan en sus valores predeterminados). Compara esto con el mismo ejemplo con flex-grow establecido al predeterminado 0 (este es el mismo comportamiento que observamos en la FIGURA 12-2).

<div id="container">
    <div class="box box1">1</div>
    <div class="box box2">2</div>
    <div class="box box3">3</div>
    <div class="box box4">4</div>
    <div class="box box5">5</div>
</div>

LOS ESTILOS

.box {
    ...
    flex: 1 1 auto;
}

Por ejemplo, dar a “box4” el valor flex-grow: 3 significa que recibe tres veces la cantidad de espacio sobrante que los elementos restantes, establecidos a flex-grow: 1. Propiedades Flex

Ahora que has sido introducido a todas las propiedades en el Módulo de Diseño de Caja Flexible CSS Nivel 1, podría ser útil ver de un vistazo qué propiedades se aplican a contenedores y cuáles se establecen en elementos flex.

Propiedades del contenedor
Aplica estas propiedades al contenedor flex:

  • display
  • flex-flow
    • flex-direction
    • flex-wrap
  • justify-content
  • align-items
  • align-content

Propiedades de elementos flex
Aplica estas propiedades a elementos flex:

  • align-self
  • flex
    • flex-grow
    • flex-shrink
    • flex-basis
  • order

NOTA

flex-grow es la propiedad individual que especifica cómo puede expandirse un elemento. Se alienta a los autores a usar la propiedad
abreviada flex en su lugar.

Las propiedades flex se aplican a elementos flex, no al contenedor.

flex: 0 1 auto; El valor predeterminado de flex-grow de 0 previene la expansión.

flex: 1 1 auto; Un valor de flex-grow de 1 permite la expansión.

Cuando flex-grow se establece a 1, el espacio extra en la línea se distribuye en los elementos en porciones iguales, y se expanden para llenar el espacio a la misma velocidad.

flex: 3 1 auto;

Asignando un valor flex-grow diferente a un elemento individual. Aquí, “box4” fue establecido para expandirse a tres veces la velocidad de los otros elementos.

.box4 {
    flex: 3 1 auto;
}

Nota que el elemento resultante no es tres veces más ancho que los otros; simplemente obtuvo tres veces la cantidad de espacio extra agregado a él.

Si no queda mucho espacio en la línea, hay una posibilidad de que cada porción de espacio pueda ser lo suficientemente pequeña que no sumaría mucha diferencia. Puede que necesites jugar con los valores flex-grow y ajustar el ancho del navegador hasta que obtengas el efecto que quieres.

Ahora que tienes ese concepto claro, el encogimiento debería ser directo, porque se basa en el mismo principio.

Comprimiendo Elementos (flex-shrink)

El segundo valor de la propiedad flex, flex-shrink, entra en acción cuando el contenedor no es lo suficientemente ancho para contener los elementos, resultando en un déficit de espacio. Esencialmente quita algo de espacio de dentro de los elementos, encogiéndolos para que encajen, según una proporción especificada.

flex-shrink

Valores: number

Predeterminado: 1

Se aplica a: Elementos flex

Hereda: No

Por defecto, el valor flex-shrink se establece a 1, lo que significa que si no haces nada, los elementos se encogen para ajustarse con el mismo ratio. Cuando flex-shrink es 0, los elementos no tienen permitido encogerse, y pueden colgar fuera de su contenedor y extenderse más allá del borde de la ventana. Finalmente, como con flex-grow, un entero más alto funciona como una proporción. Un elemento con un flex-shrink de 2 se encogerá dos veces más que si estuviera establecido a 1. Generalmente no necesitarás especificar un valor de proporción de encogimiento; simplemente activar el encogimiento (1) o desactivarlo (0) debería ser suficiente.

Eventualmente, queremos que nuestros elementos flex dejen de encogerse. Por defecto, esto sucede cuando alcanzan su tamaño mínimo, que se basa en el tamaño más pequeño en que el contenido puede caber (min-content). Por ejemplo, el ancho más pequeño posible de un elemento que contiene el texto “The dog jumps” se basa en la palabra “jumps”—ese es el ancho más pequeño en que el contenido puede caber sin tener que dividir palabras en múltiples líneas.

Puedes ajustar fácilmente el tamaño mínimo usando las propiedades min-width/min-height para establecer la longitud a 0, 12em, o cualquier otra longitud que parezca útil. Ten cuidado con este efecto cuando elementos profundamente anidados fuercen a un elemento flex a ser más ancho de lo esperado.

Proporcionando un Tamaño Inicial (flex-basis)

El tercer valor flex define el tamaño inicial del elemento antes de que ocurra cualquier envolvimiento, crecimiento o encogimiento (flex-basis). Puede usarse en lugar de la propiedad width (o propiedad height para columnas) para elementos flex.

**

flex-basis**

Valores: length | percentage | content | auto

Predeterminado: auto

Se aplica a: Elementos flex

Hereda: No

En este ejemplo, el flex-basis de las cajas se establece a 100 píxeles Los elementos tienen permitido encogerse más pequeños para caber en el espacio disponible (flex-shrink: 1), pero no tienen permitido crecer más anchos (flex-grow: 0) que 100 píxeles, dejando espacio extra en el contenedor:

.box {
    flex: 0 1 100px;
}

Por defecto, los elementos pueden encogerse cuando el contenedor no es lo suficientemente ancho (flex-shrink: 1).

flex: 0 1 100px;

Cuando el contenedor es ancho, los elementos no crecerán más anchos que su flex-basis de 100 píxeles porque flex-grow está establecido a 0.

Cuando el contenedor es estrecho, los elementos tienen permitido encogerse para ajustarse (flex-shrink: 1).

Usando flex-basis para establecer el ancho inicial de los elementos

Por defecto, flex-basis se establece a auto, que usa los valores de propiedad width/height especificados para el tamaño del elemento. Si la propiedad de tamaño principal del elemento (width o height) no está establecida, o está establecida a auto (su predeterminado), flex-basis usa el ancho del contenido. También puedes establecer explícitamente flex-basis para que sea el ancho del contenido con la palabra clave content.

.box {
    width: 300px;
    flex: 1 0 auto;
}

En este ejemplo, el flex-basis para las cajas sería 300 píxeles porque el valor auto para flex-basis usa el valor establecido por la propiedad width. Los elementos tienen permitido crecer más anchos, tomando cualquier espacio extra en el contenedor, pero no tienen permitido encogerse:

Cuando el navegador se encarga de dimensionar un elemento flex, consulta el valor flex-basis, lo compara con el espacio disponible a lo largo del eje, y luego agrega o quita espacio del elemento según sus configuraciones de crecimiento y encogimiento. Es importante notar que si permites que un elemento crezca o se encoja, podría terminar siendo más estrecho o más ancho que la longitud proporcionada por flex-basis o width.

Valores Abreviados Útiles de flex

La ventaja de usar la propiedad flex es que hay algunos valores abreviados útiles que cubren escenarios típicos de Flexbox. Algunos de los valores abreviados anulan los predeterminados de las propiedades individuales, pero al final resulta en comportamientos más predecibles. Cuando especifiques flex para elementos, ve si una de estas configuraciones fáciles hará el truco:

*Las configuraciones flex anulan los anchos/alturas especificados para elementos flex.

Cambiando el Orden de Elementos Flex

flex: initial;
Esto es lo mismo que el flex: 0 1 auto predeterminado. Previene que el elemento flex crezca incluso cuando hay espacio extra, pero le permite encogerse para ajustarse en el contenedor. El tamaño se basa en las propiedades width/height especificadas, por defecto al tamaño del contenido. Con el valor initial, puedes usar justify-content para alineación horizontal.

flex: auto;
Esto es lo mismo que flex: 1 1 auto. Permite que los elementos sean completamente flexibles, creciendo o encogiendo según sea necesario. El tamaño se basa en las propiedades width/height especificadas.

flex: none;
Esto es equivalente a flex: 0 0 auto. Crea un elemento flex completamente inflexible, dimensionándolo según los valores de las propiedades width y height. También puedes usar justify-content para alineación cuando flex está establecido a none.

flex: integer;
Esto es lo mismo que flex: integer 1 0%. El resultado es un elemento flexible con un flex-basis de 0, lo que significa que tiene flex absoluto (ver la barra lateral “Flex Absoluto Versus Relativo”) y el espacio extra se asigna usando el entero especificado como proporción.

CAMBIANDO EL ORDEN DE ELEMENTOS FLEX

Una característica útil de Flexbox es la capacidad de mostrar elementos en un orden que difiere de su orden en el código fuente (ver la barra lateral “Cuándo Reordenar (y Cuándo No)”). Esto significa que puedes cambiar el orden de diseño de elementos usando solo CSS. Esto es poderoso para diseño responsivo, permitiendo que el contenido de más adelante en un documento se mueva hacia arriba en pantallas más pequeñas.

Para cambiar el orden de elementos, aplica la propiedad order a los elementos particulares que deseas mover.

order

Valores: integer

Predeterminado: 0

Se aplica a: Elementos flex e hijos posicionados absolutamente de contenedores flex

Hereda: No

El valor de la propiedad order es un número positivo o negativo que afecta la colocación del elemento a lo largo de la línea flex. Es similar a la propiedad z-index en que el valor numérico específico no importa, solo cómo se relaciona con otros valores.

Cuándo Reordenar (y Cuándo No)

Ten en cuenta que aunque es conveniente, reordenar solo da un truco visual y debe usarse con discreción. Algunos puntos a recordar:

• Aunque los elementos se muestren en un orden diferente para navegadores visuales, dispositivos alternativos como lectores de pantalla aún leen el contenido en el orden en que aparece en el código fuente (aunque este comportamiento no es 100% confiable en el mundo real).

• Reordena el código fuente si hay una razón lógica (más que visual) para el reordenamiento.

• No uses order porque es más conveniente.

• Usa order si el orden lógico y visual están destinados a ser diferentes.
Con flex absoluto (cuando flex-basis se establece a 0), las cajas se dimensionan proporcionalmente según sus proporciones flex.

Por defecto, todos los elementos tienen un valor order de cero (0). Cuando los elementos tienen el mismo valor order, se disponen en el orden en que aparecen en el código fuente HTML. Si tienen valores order diferentes, se organizan desde el valor order más bajo al más alto.

Volviendo a nuestro ejemplo de caja numerada colorida, aquí le he dado a box3 un valor order de 1. Con un valor order más alto, aparece después de todos los elementos establecidos a 0 (el predeterminado).

.box3 {
    order: 1;
}

Cuando especifiques flex para elementos, ve si puedes aprovechar uno de los atajos útiles de flex.

Cambiando el orden de elementos con la propiedad order. Establecer box3 a order: 1 hace que se muestre después del resto.

Cuando múltiples elementos comparten el mismo valor order, ese grupo de elementos que comparten valores (llamado un grupo ordinal) se mantienen juntos y se muestran en orden de código fuente. ¿Qué pasa si le damos a box2 un valor order de 1 también? Ahora tanto box2 como box3 tienen un valor order de 1 (convirtiéndolos en un grupo ordinal), y se muestran en orden de código fuente después de todos los elementos con el valor order más bajo de 0

.box2, .box3 {
    order: 1;
}

Establecer box2 a order: 1 también hace que se muestre después de los elementos con el order predeterminado de 0, pero antes que box3.

También puedes usar valores negativos para order. Para continuar con nuestro ejemplo, aquí le he dado a box5 un valor order de −1. Nota en la FIGURA 17-25 que no solo se mueve hacia atrás un espacio; se mueve antes que todos los elementos que aún tienen order establecido a 0, que es un valor más alto que −1:

.box5 {
    order: -1;
}

Los valores negativos se muestran antes que los elementos con el order predeterminado de 0.

He usado valores simples de 1 y −1 en estos ejemplos, pero el
resultado sería el mismo si hubiera usado valores como 10008 o −649.
El orden va del valor más bajo al más alto, y los valores numéricos no
necesitan estar en orden secuencial.

Flex Absoluto Versus Relativo

En la FIGURA 12-20, vimos cómo se asigna el espacio extra a los elementos basado en sus proporciones flex. Esto se llama flex relativo, y es cómo se maneja el espacio extra cuando el flex-basis se establece a cualquier tamaño que no sea cero (0), como un valor particular de width/height o auto.

Sin embargo, si estableces el valor de flex-basis a 0, algo interesante sucede. Con una base de 0, los elementos se dimensionan proporcionalmente según sus proporciones flex, lo que se conoce como flex absoluto. Entonces, con flex-basis: 0%, un elemento con un valor flex-grow de 2 sería dos veces más ancho que cualquier elemento con un valor flex-grow de 1. Nuevamente, esto solo entra en acción cuando el flex-basis es 0.

En la práctica se recomienda que siempre incluyas una unidad después del 0, como 0px o el preferido 0%.

En este ejemplo de flex absoluto, a la primera caja se le da un valor flex-grow de 2, y a la cuarta caja tiene un valor flex-grow de 3 a través del atajo mencionado anteriormente flex: integer. En la FIGURA 17-22, puedes ver que los tamaños generales resultantes de las cajas están en proporción a los valores flex-grow porque el flex-basis se establece a 0:

.box {
    /* applied to all boxes */
    flex: 1 0 0%;
}
.box1 {
    flex: 2; /* shortcut value for flex: 2 1 0% */
}
.box4 {
    flex: 3; /* shortcut value for flex: 3 1 0% */
}

FLEXBOX PARA DISEÑO DE PÁGINA

Ahora echemos un vistazo a cómo podemos usar order para algo más útil que mover pequeñas cajas en una línea. Aquí hay un documento simple con un encabezado, una sección principal que consiste en un article y dos elementos aside, y un footer (ver Nota):

<header>...</header>
<main>
    <article><h2>Where It's At</h2></article>
    <aside id="news"><h2>News</h2></aside>
    <aside id="contact"><h2>Contact</h2></aside>
</main>
<footer>...</footer>

Aquí he hecho del elemento main un contenedor flex para que los elementos article y aside se alineen en una fila, creando tres columnas ). Establecí el factor flex para cada elemento, permitiéndoles crecer y encogerse, y establecí sus anchos con flex-basis. Finalmente, usé la propiedad order para especificar el orden en que me gustaría que aparezcan. Nota que la sección Contact ahora es la primera en la fila, aunque aparece última en el orden del código fuente. Y, como beneficio adicional, todas las columnas llenan la altura del contenedor principal a pesar de la cantidad de contenido en ellas porque stretch es el valor predeterminado para align-items:

main {
    display: flex;
}
article {
    flex: 1 1 50%;
    order: 2;
}
#news {
    flex: 1 1 25%;
    order: 3;
}
#contact {
    flex: 1 1 25%;
    order: 1;
}
