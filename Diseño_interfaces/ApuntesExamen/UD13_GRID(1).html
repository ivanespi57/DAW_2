GRID LAYOUT

A muchos de nosotros nos gusta alinear las cosas en filas y columnas, por lo que no es sorprendente que el W3C y los navegadores hayan tardado más de un siglo en proporcionar una forma confiable de distribuir elementos y páginas en una cuadrícula. Claro, logramos diseños elegantes con tablas y flotantes, pero esos eran esencialmente trucos. El Módulo CSS Grid Layout proporciona un verdadero sistema para distribuir elementos en filas y columnas (recuerda que Flexbox distribuye elementos en un solo eje). Las cuadrículas pueden permanecer completamente flexibles para adaptarse a una variedad de tamaños de pantalla, o pueden ser rígidas, para imitar un diseño de página impresa. Puedes usarlas para componentes de página que organizan varios elementos individuales (como una galería de fotos) o para crear diseños sofisticados de página

El Módulo CSS Grid Layout Nivel 2 (w3.org/TR/css-grid-2/) es uno de los módulos más complejos en CSS, por lo que tenemos mucho terreno que cubrir en este capítulo. Aquí está el plan:

RESUMEN DE GRID LAYOUT

Comencemos familiarizándonos con cómo funcionan las cuadrículas. Grid Layout es un modo de visualización que permite organizar elementos en dos dimensiones (filas y columnas). Acabas de aprender sobre el modo de visualización Flexbox que, por el contrario, organiza elementos a lo largo de un solo eje. La FIGURA 18-2 compara la misma galería configurada con display: flex versus display: grid.

display: flex;
Los elementos se alinean horizontalmente

display: grid;
Los elementos se alinean horizontal y verticalmente

FIGURA 18-2. La diferencia entre Flexbox y Grid Layout

Puedes ver que en el ejemplo de Grid Layout, todas las imágenes se alinean perfectamente una debajo de la otra a lo largo de sus bordes izquierdos. En el ejemplo de Flexbox, aunque las imágenes fluyen en múltiples líneas, las imágenes en la segunda y tercera líneas no se alinean con las imágenes en las líneas de arriba. Ten en cuenta que si tienes contenido que no necesita estar alineado en columnas, Flexbox puede ser la única herramienta que necesites. En la práctica, es común que Grid Layout y Flexbox se usen juntos para lograr el diseño de una página y sus componentes.

Terminología de Grid

Antes de llegar al código, hagamos una pausa aquí para ver las partes de una cuadrícula según la especificación. Una cuadrícula tiene varios componentes, como se ilustra en la FIGURA 18-3.

Estos términos serán útiles para las próximas discusiones:

línea de cuadrícula
Las líneas divisorias horizontales y verticales de la cuadrícula se llaman líneas de cuadrícula.

celda de cuadrícula
La unidad más pequeña de una cuadrícula es una celda de cuadrícula, que está bordeada por cuatro líneas de cuadrícula adyacentes (sin líneas de cuadrícula que la atraviesen).

área de cuadrícula
Un área de cuadrícula es un área compuesta por una o más celdas de cuadrícula adyacentes. Un área de cuadrícula debe ser rectangular; en otras palabras, puede no tener forma de “L” o cualquier otra forma.

pista de cuadrícula
El espacio entre dos líneas de cuadrícula adyacentes es una pista de cuadrícula, que es un nombre genérico para una fila de cuadrícula o una columna de cuadrícula.

eje en línea
El eje en línea es la dirección en la que fluye el texto en línea basado en el idioma del documento. En inglés, el texto fluye horizontalmente; por lo tanto, el eje en línea en las cuadrículas es horizontal. Las filas de cuadrícula siguen el eje en línea.

eje de bloque
El eje de bloque es la dirección en la que aparecen los bloques en un diseño de bloque, basado en la dirección del idioma. En inglés, el eje de bloque es vertical porque los bloques se distribuyen de arriba hacia abajo. Las columnas de cuadrícula siguen el eje de bloque.

Contenedores e Elementos de Grid

Una cuadrícula está compuesta por un contenedor y algún número de elementos. Cuando aplicas la propiedad display: grid a un elemento, se convierte en el contenedor de cuadrícula y define el contexto para el formato de cuadrícula. Todos sus elementos hijos directos automáticamente se convierten en elementos de cuadrícula que terminan posicionados en la cuadrícula.

Las palabras importantes en el párrafo anterior son “hijo directo”, ya que solo esos elementos contenidos dentro de esos elementos no participan en la cuadrícula, por lo que no puedes colocar elementos anidados. Sin embargo, puedes anidar una cuadrícula dentro de otra cuadrícula si necesitas aplicar una cuadrícula a un nivel más profundo.

Para convertir un elemento en un contenedor de cuadrícula, establece su propiedad display en grid o inline-grid

NOTA
Las cuadrículas en línea funcionan igual que las cuadrículas a nivel de bloque, pero pueden usarse en el flujo de contenido. Me enfocaré solo en las cuadrículas a nivel de bloque en este capítulo.

En este ejemplo simple, el div #layout se convierte en un contenedor de cuadrícula, y cada uno de sus hijos (#one, #two, #three, #four, y #five) se convierte en un elemento de cuadrícula.

HTML

<div id="layout">
    <div id="one">One</div>
    <div id="two">Two</div>
    <div id="three">Three</div>
    <div id="four">Four</div>
    <div id="five">Five</div>
</div>

CSS

#layout {
    display: grid;
}

Ahora que conoces algunos conceptos básicos, veamos qué puede hacer el algoritmo de cuadrícula directamente con muy poca instrucción.

CUADRÍCULAS IMPLÍCITAS Y COMPORTAMIENTO PREDETERMINADO DE GRID

La FIGURA 18-4 muestra cómo se ve el ejemplo anterior con cinco elementos de cuadrícula si lo abres en un navegador. He aplicado algunos estilos de fuente y colores de fondo que no se muestran en el código de ejemplo para hacer la estructura clara.

Sin especificar ningún estilo adicional relacionado con cuadrícula, terminamos con una cuadrícula con una columna (la predeterminada) y cinco filas. Aunque parece que no está pasando mucho, hay algunos comportamientos importantes de cuadrícula ocurriendo aquí:

• Un elemento de cuadrícula se coloca en cada celda, que es el comportamiento predeterminado.

• El algoritmo de cuadrícula genera automáticamente suficientes filas para colocar todos los elementos de cuadrícula en el contenedor. En este ejemplo, tenemos cinco filas para cinco elementos porque nuestra cuadrícula tiene solo una columna (la predeterminada).

• Por defecto, la altura de las filas es justo lo suficientemente alta para contener el contenido del elemento (auto).

Una cuadrícula que resulta del navegador agregando automáticamente filas o columnas para contener todos los elementos se llama una cuadrícula implícita. Es lo que obtienes cuando simplemente dejas que el algoritmo de cuadrícula haga lo suyo. Por el contrario, cuando defines una cuadrícula con un número específico de filas y columnas, creas una cuadrícula explícita. Por ahora, nos vamos a enfocar en el comportamiento de cuadrícula implícita.

Démosle a esa misma cuadrícula tres columnas, cada una de 300 píxeles de ancho, con la propiedad grid-template-columns. Hablaré mucho más sobre esta propiedad y sus valores más adelante en el capítulo, pero por ahora solo presta atención a cómo los elementos se colocan automáticamente en las celdas de cuadrícula (FIGURA 18-5):

#layout {
    display: grid;
    grid-template-columns: 300px 300px 300px;
}

Una cuadrícula que resulta del navegador agregando automáticamente filas o columnas para contener todos los elementos se llama una cuadrícula implícita.**

Observa que los elementos se colocan de izquierda a derecha, y se agrega una nueva fila debajo de la primera. Eso es porque las cuadrículas son conscientes de la dirección de escritura del documento en el que están. El documento de ejemplo está escrito en inglés, por lo que los elementos fluyen automáticamente en filas de izquierda a derecha y de arriba hacia abajo. En un documento árabe o hebreo, las filas se llenarían desde el borde de recho hacia la izquierda.

El comportamiento automático de generación de filas y columnas del algoritmo de cuadrícula es realmente útil, y para algunos propósitos, una cuadrícula implícita puede ser todo lo que necesites. Por ejemplo, si solo quieres una presentación ordenada de fotos en una galería (como la de la FIGURA 18-2), puedes especificar el número de columnas y dejar que el navegador maneje el resto. La cuadrícula implícita también es útil cuando tienes un número desconocido de elementos o si el número de elementos en el contenedor puede cambiar dinámicamente.

Propiedades de Cuadrícula Implícita

El módulo Grid Layout proporciona algunas propiedades para controlar el tamaño de las pistas generadas automáticamente y la manera en que los elementos fluyen hacia ellas.

Dimensionamiento de pistas implícitas

Como has visto en los ejemplos anteriores, cualquier fila o columna agregada a una cuadrícula implícita será dimensionada lo suficientemente grande para acomodar la altura o ancho de los contenidos. Si quieres dar a las filas y columnas generadas automáticamente dimensiones específicas, usa las propiedades grid-auto-.

  • grid-auto-rows

  • grid-auto-columns

Valores: lista de tamaños de pista
Predeterminado: auto
Se aplica a: Contenedores de cuadrícula
Hereda: No

Las propiedades grid-auto-row y grid-auto-columns se aplican al contenedor de cuadrícula. Sus valores son una lista de uno o más tamaños de pista que se usarán para las pistas generadas automáticamente (de ahí el término “auto” en los nombres de las propiedades). Para hacer que las filas de nuestra cuadrícula implícita de ejemplo tengan 4em de altura (FIGURA 18-6), agrega esta declaración a los estilos para el contenedor de cuadrícula:

#layout {
    display: grid;
    grid-template-columns: 300px 300px 300px;
    grid-auto-rows: 4em;
}

Dirección de flujo

grid-auto-flow

Valores: row o column | dense (opcional)
Predeterminado: row
Se aplica a: Contenedores de cuadrícula
Hereda: No

Hasta ahora, solo hemos visto elementos fluyendo en filas, pero puedes usar la propiedad grid-auto-flow para hacer que los elementos fluyan por columnas en su lugar, como se muestra en este ejemplo:

#listings {
    display: grid;
    grid-auto-flow: column;
}

Si la altura del contenedor de cuadrícula está limitada, el algoritmo de cuadrícula automáticamente agrega columnas implícitas a la derecha hasta que todos los elementos de cuadrícula estén acomodados, tal como vimos para las filas.

Densidad de cuadrícula

Por defecto, los elementos se colocan en la primera área en la que caben. Las celdas que son demasiado pequeñas para acomodar el contenido serán omitidas hasta que se encuentre una celda lo suficientemente grande para colocarlo. Si incluyes la palabra clave opcional dense para la propiedad grid-auto-flow, instruye al navegador a llenar la cuadrícula tan densamente como sea posible, permitiendo que los elementos aparezcan fuera de secuencia en orden para llenar el espacio disponible:

#listings {
    display: grid;
    grid-auto-flow: dense rows;
}

El ejemplo de la izquierda en la FIGURA 18-7 muestra el método de flujo predeterminado. He usado bloques numerados y coloreados, pero podrías imaginar que estos son fotos con dimensiones intrínsecas. Mira de cerca, y verás que los elementos de cuadrícula están en orden. Cuando no hay suficiente espacio para todo el elemento en la siguiente celda disponible, intenta la siguiente celda, moviéndose al inicio de una nueva fila si no cabe en la celda final disponible de la fila actual (similar a los flotantes). Este método puede dejar celdas vacías, como se muestra en la figura. Por comparación, el ejemplo de flujo denso a la derecha está todo lleno, y si miras la numeración, puedes ver que poner elementos en el primer espacio disponible donde caben los hace terminar fuera de orden. Ten en cuenta que el flujo denso no siempre resulta en una cuadrícula completamente llena como en esta figura, pero es probable que tenga menos huecos y sea más compacta que el modo predeterminado.
